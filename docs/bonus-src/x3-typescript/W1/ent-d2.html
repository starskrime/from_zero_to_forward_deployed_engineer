npm install @anthropic-ai/sdk (it reads ANTHROPIC_API_KEY). Call client.messages.create({ model: "claude-haiku-4-5", max_tokens: 300, messages: [...] }). The reply's content is an array of blocks with different shapes, so TypeScript makes you check the type before reading .text. This is a type guard:

const text = response.content
  .filter((b): b is Anthropic.TextBlock => b.type === "text")
  .map(b => b.text)
  .join("");
