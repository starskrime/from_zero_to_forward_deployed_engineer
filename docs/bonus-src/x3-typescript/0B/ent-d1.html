Enterprise · TypeScript I: why, setup, basic types

Customer front-ends, many SDKs, and a lot of agent tooling are written in TypeScript. You don't need to become a front-end engineer, but you need to read it, debug it and write small modules in it. TypeScript is JavaScript plus types, much like Python's type hints, except the checker is built in.

  1. Install the LTS version of Node.js from nodejs.org. Check with node --version.
  2. Recent Node versions run .ts files directly by stripping the types, so there's no build step for small scripts: node lead.ts.
  3. In code/week-0B/ts/lead.ts, write parseCreditScore(raw: string): number that throws an Error for empty input, non-whole numbers, and values outside 300–850, just like your Python version.
function parseCreditScore(raw: string): number {
  if (raw.trim() === "") throw new Error("credit_score is missing");
  const score = Number(raw);
  if (!Number.isInteger(score)) throw new Error(`not a whole number: ${raw}`);
  if (score < 300 || score > 850) throw new Error(`credit_score ${score} is outside 300-850`);
  return score;
}
