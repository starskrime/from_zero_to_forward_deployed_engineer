Enterprise · TypeScript IV: working with arrays

Most TypeScript you'll read transforms arrays of objects. Write perState.ts: given an array of Lead objects, return an object counting leads per state, and a list of lead IDs with a credit score of 740 or more, using filter, map and reduce.

const highScores = leads.filter(l => l.creditScore >= 740).map(l => l.leadId);
const perState = leads.reduce<Record<string, number>>((acc, l) => {
  acc[l.state] = (acc[l.state] ?? 0) + 1;
  return acc;
}, {});

Compare with your Python: filter/map ≈ list comprehensions, reduce into an object ≈ Counter, and ?? ≈ "use this default if the value is missing".
