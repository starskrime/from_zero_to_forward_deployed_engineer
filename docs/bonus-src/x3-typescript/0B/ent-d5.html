Enterprise · TypeScript V: a tiny tested module

Node has a built-in test runner. Move parseCreditScore and parseLoanType into parse.ts (with export in front of each), and write parse.test.ts:

import { test } from "node:test";
import assert from "node:assert/strict";
import { parseCreditScore } from "./parse.ts";

test("accepts a valid score", () => {
  assert.equal(parseCreditScore("742"), 742);
});

test("rejects out-of-range scores", () => {
  assert.throws(() => parseCreditScore("905"));
});
$ node --test

Add three more tests (empty, "7.5", and an unknown loan type). You now have the same testing habit in both languages.
