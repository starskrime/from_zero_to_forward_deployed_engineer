Updates

The start script checks GitHub when it starts and once a day while it runs, then updates the platform with a safe fast-forward. Your own work in code/ is never touched. See what's new.

Checking the update status…

To turn automatic updates off, start the platform with the --no-update option: on macOS or Linux run the first line, on Windows run the second from a Command Prompt.

bash start.sh --no-update
start.bat --no-update

To update by hand at any time: git pull --ff-only in the platform folder. A browser page can't change how the server runs, so this setting lives in the start command.
